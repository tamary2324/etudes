            Donc : $\frac{y_{n}-y_{n-1}}{T_e} + \frac{y_n}{\tau} = \frac{x_n}{\tau}$

            Soit : $y_{n} = \frac{1}{1+\frac{\tau}{T_e}}\parenth{y_{n-1}\frac{\tau}{T_e}+x_n}$
            
            D'où : $\alpha = \frac{\tau}{T_e} = 20$
